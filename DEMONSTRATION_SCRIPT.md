# Demonstration Script — AI Financial Analyst Agent

Public URL: https://coca-cola-financial-analyst.streamlit.app

## Suggested live demo order (3–5 minutes)
1. Open the public URL — show Home / Dashboard
2. Open Financial Data — show 14 items for 2025 & 2024
3. Open Data Validation — show PASS status
4. Open Ratio Analysis — expand one ratio (formula + calculation + result)
5. Open Two-Year Comparison — show movements
6. Open Strengths & Weaknesses
7. Open Full Financial Report — scroll key sections
8. Click Download Report
9. (Optional) Page 9 Automation — explain Zapier → Google Sheets

## Talking points
- All figures from official Coca-Cola Form 10-K
- No fabricated data
- Agent validates before calculating
- Missing data → "Not calculable" (never invents)
- 13 ratios + 14-section report
- Excel formulas independently confirm agent results
