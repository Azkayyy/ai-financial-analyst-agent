# AI Financial Analyst Agent
## University Assignment — Task 3

**Company demonstrated:** The Coca-Cola Company (NYSE: KO)  
**Industry:** Beverage / Consumer Staples Manufacturing  
**Currency / Units:** USD millions  
**Financial Years:** 2025 and 2024  

---

## What this application does

This is a **functional AI Financial Analyst Agent** built with Streamlit. It is **not** a static dashboard.

The agent:
1. Receives / loads financial data (verified Coca-Cola dataset pre-loaded; user can also upload Excel/CSV)
2. Validates the data (missing values, type checks, consistency)
3. Calculates all 13 required financial ratios using the exact verified methodology from Task 2 & Task 4
4. Explains each ratio with formula, figures used, calculation, result and descriptive interpretation
5. Compares FY2025 vs FY2024
6. Identifies financial strengths and weaknesses from the calculated movements only
7. Highlights potential risks / red flags (data-driven, no fabrication)
8. Generates a complete 14-section professional financial analysis report
9. Allows download of the report

**Calculations are deterministic.** AI-style interpretation is used only for structured commentary. No financial figures are ever invented.

## How to run locally (for testing)

1. Install Python 3.9+
2. Open a terminal in this folder
3. Create a virtual environment (recommended):
   ```bash
   python -m venv venv
   # Windows:
   venv\Scripts\activate
   # macOS / Linux:
   source venv/bin/activate
   ```
4. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
5. Run the app:
   ```bash
   streamlit run app.py
   ```
6. The app will open in your browser at `http://localhost:8501`

## How to deploy to Streamlit Community Cloud (public shareable URL)

This is the recommended way to obtain a **real public URL** that you can send to your teacher.

### Step-by-step

1. **Create a free GitHub account** (if you do not already have one) → https://github.com

2. **Create a new public repository** on GitHub (e.g. `ai-financial-analyst-agent`)

3. **Upload all files** from this folder into the repository:
   - `app.py`
   - `verified_coca_cola_data.json`
   - `requirements.txt`
   - `README.md`

4. **Go to Streamlit Community Cloud** → https://share.streamlit.io  
   Sign in with your GitHub account.

5. Click **“New app”**

6. Select:
   - Repository: the one you just created
   - Branch: `main` (or `master`)
   - Main file path: `app.py`

7. Click **Deploy**

8. Wait 1–2 minutes. Streamlit will give you a public URL that looks like:
   ```
   https://your-app-name.streamlit.app
   ```

9. Copy that URL and send it to your teacher. Anyone with the link can open and use the agent.

## Data integrity rules enforced by the agent

- Uses only the verified Task 2 figures for Coca-Cola demonstration
- Never invents or estimates missing values
- Clearly states when a ratio cannot be calculated
- Treats 2023 figures strictly as supporting beginning balances
- Separates calculated numerical results from descriptive interpretations
- Does not provide investment advice
